# Loader Component

This directory contains a customizable loader/spinner component built with HTML and CSS. It is designed to be easily integrated into any web project to indicate loading states or background processing.

## File Structure

- `index.html`: Contains the structural markup for the loader.
- `style.css`: Contains the animations, layout, and visual styling for the loader.

## Usage

To use this loader in your project:

1. Copy the HTML structure from `index.html` into your target file where the loader should appear.
2. Link or copy the CSS from `style.css` into your project's stylesheet.

## Customization

You can easily customize the loader's appearance by modifying the CSS properties within `style.css`:
- **Colors:** Update the `stroke`, `background`, or `border` colors depending on the loader style.
- **Size:** Adjust the `width` and `height` properties of the main loader container.
- **Animation Speed:** Tweak the `animation-duration` property defined in the keyframes.
